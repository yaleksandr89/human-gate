# IconSequence

В этой CAPTCHA пользователь видит последовательность значков на изображении и должен выбрать такие же значки в том же порядке. Здесь важны не только выбранные варианты, но и последовательность нажатий.

## Подключение и пример

Для создания задания используется `IconSequenceStrategy`. Вариант с настройками по умолчанию выглядит так:

```php
<?php

use Yaleksandr\HumanGate\IconSequence\IconSequenceStrategy;

$strategy = new IconSequenceStrategy();
```

При необходимости параметры можно передать явно:

```php
<?php

use Yaleksandr\HumanGate\IconSequence\IconSequenceBlur;
use Yaleksandr\HumanGate\IconSequence\IconSequenceOptions;
use Yaleksandr\HumanGate\IconSequence\IconSequenceRenderOptions;
use Yaleksandr\HumanGate\IconSequence\IconSequenceStrategy;

$strategy = new IconSequenceStrategy(
    new IconSequenceOptions(sequenceLength: 4, choiceCount: 8),
    new IconSequenceRenderOptions(
        minIconSize: 72,
        maxIconSize: 80,
        blur: IconSequenceBlur::Strong,
        noisePercent: 150,
        maxRotationDegrees: 90,
    ),
);
```

Стратегия передаётся в `ChallengeService`, а при создании задания через [`issue()`](../reference/api.md#issue) указывается `ChallengeKind::IconSequence`. Пример полной сборки сервиса приведён в [руководстве по интеграции](../guides/integration.md).

## Длина последовательности и варианты

| Параметр `IconSequenceOptions` | По умолчанию | Допустимые значения |
| --- | --- | --- |
| `sequenceLength` | `4` | От `3` до `6` значков в задании |
| `choiceCount` | `8` | Не меньше `sequenceLength + 2`, не больше `12` |

Например, при четырёх значках в цели пользователь получает восемь вариантов, среди которых нужно выбрать четыре в правильном порядке. Другие варианты служат для усложнения задания.

## Настройка изображения

| Параметр `IconSequenceRenderOptions` | По умолчанию | Допустимые значения |
| --- | --- | --- |
| `minIconSize` | `72` | От `72` до `96` пикселей |
| `maxIconSize` | `80` | От `72` до `96`, не меньше `minIconSize` |
| `blur` | `IconSequenceBlur::Strong` | `None`, `Light`, `Standard`, `Strong` |
| `noisePercent` | `150` | От `0` до `150` |
| `maxRotationDegrees` | `90` | От `0` до `90` градусов |

Размер и поворот должны подходить друг другу: даже отдельно допустимые значения не всегда можно сочетать, потому что повёрнутый значок должен помещаться в изображение цели высотой 128 пикселей.

Размытие, шум и поворот применяются к изображению задания. Изображения отдельных вариантов остаются чёткими. Срок действия задаётся отдельно через [`Policy::ttlSeconds`](../reference/api.md#policy), по умолчанию 180 секунд.

## Данные для отображения

[`IconSequencePresentation`](../reference/api.md#данные-для-интерфейса) содержит:

| Поле | Назначение |
| --- | --- |
| `target` | Изображение с последовательностью для повторения |
| `requiredSelections` | Число значков, которое нужно выбрать |
| `choices` | Список вариантов `IconSequenceChoice` с полями `token` и `image` |

Целевое изображение и варианты передаются как `ImagePresentation` с PNG-байтами. Каждое изображение варианта имеет размер 96×96 пикселей. У целевого изображения высота 128 пикселей, а ширина зависит от длины последовательности.

Браузер получает изображения и непрозрачные токены. Данные `IconSequenceChoice` не содержат названий значков или сведений о правильном порядке.

## Формат ответа

Приложение собирает токены выбранных значков в строку через запятую **строго в порядке выбора пользователя** и передаёт её в [`verify()`](../reference/api.md#verify).

Токены имеют формат из 32 строчных шестнадцатеричных символов. Для одного ответа выбираются от трёх до шести разных токенов; максимальная длина строки составляет 197 байт. Библиотека не сортирует токены и не удаляет пробелы. Некорректный порядок или формат приводят к неверному ответу.

После успешного [`replace()`](../reference/api.md#replace) нужно очистить прежнюю последовательность выбора и показать новые изображения. Остальные правила приведены в [описании жизненного цикла](../reference/lifecycle.md).

## Безопасность и доступность

Правильная последовательность определяется на сервере. Добавлять в HTML названия значков, правильные позиции или другие данные, позволяющие восстановить ответ, нельзя. Подробнее этот принцип описан в [модели безопасности](../security-model.md).

В интерфейсе допустимы нейтральные названия кнопок, например «Вариант 1», и сообщения о порядке уже выбранных значков. Они не заменяют возможность визуально сопоставлять изображения, поэтому приложение предусматривает [альтернативный доступный способ проверки](../accessibility.md).

Библиотека включает 32 значка, подготовленных из Tabler Icons `v3.48.0` под лицензией MIT. Сведения об исходных ресурсах и лицензии находятся в [метаданных значков](../../resources/icons/tabler/SOURCE.txt) и [лицензии](../../resources/icons/tabler/LICENSE.txt).

Ошибки некорректных настроек вызывают `InvalidArgumentException`, а ошибки создания изображений — `RenderingException`. Неверный пользовательский ответ возвращает `Incorrect` или `AttemptsExhausted` при исчерпании попыток.
